# Gold set for the offline location lookup (tools/shared/js/location/).
# Real-world inputs as they come in on a check-in net or from the public in a
# crisis, with what the lookup must find. Evaluated by scripts/eval_location.mjs
# (`just eval-location`) and tests/location-goldset.test.mjs (real data only).
#
# One case per line:  category | query | expect | rank | flags
#   expect  label substring (case-insensitive), "@lat,lon" (within 400 m) or
#           "@lat,lon/r" (within r m); several alternatives with " OR ";
#           "-" = nothing should be found confidently (no auto-select)
#   rank    the expected place must be among the first <rank> results
#   flags   auto   = must be auto-selected (default threshold 'high')
#           noauto = must NOT be auto-selected
#
# "min <category> <share>" lines set the minimum top-<rank> hit rate the test
# enforces per category; "max-wrong-auto <n>" caps the cases with a wrong or
# forbidden auto-selection (all categories). Both are ratchets: tighten them
# when the lookup improves, never loosen one without saying why in the commit.

max-wrong-auto 0
# Categories that depend on live data (GIP names, addresses: refetched on
# every build after 30 days) keep a little slack; the core ones none.

min historical 0.9
min relation 1.0
min intersection 0.94
min context 0.95
min typo 0.9
min umland 0.9
min ambiguous 1.0
