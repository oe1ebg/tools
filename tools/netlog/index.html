                                Backup and data

                                A backup is a plain JSON file: anyone with the file can read it. Deleting something here does not delete copies already exported.

                                Station profiles

                                  Station lookup links

                                  Netlog only offers links to QRZ.com, HamQTH, QRZCQ, APRS.fi and your Wavelog; they need internet and are opened only by you. Nothing is looked up or sent by itself.

                                  Erase permanently

                                  Deleting a session, station or note is reversible (restore, undo). Erasing removes it from this device for good, with its history and drafts.

                                  ⬇

                                  Work without a server

                                  Netlog as one HTML file with the callsign and repeater lists, about 1 MB, for a USB stick or laptop: runs without a server and without internet. Its data is stored by the browser for that file, separately from this installed version; move data between them with a backup (JSON).
