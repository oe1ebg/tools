Wavelog import

needs internet · the other tools stay offline

Bring QSOs in from Wavelog

Fetches the QSOs of a logbook from your Wavelog instance and stores them on this device in the shared callsign store. Netlog then uses them offline for name, QTH and "already worked". Nothing is written to Wavelog. The token is not stored and is cleared from the field after the import. The import is not part of any backup; repeat it any time.

1 · Connection

https:// (http:// only for localhost), without user name or password. It is remembered; Netlog uses it for the "Wavelog" link at a station.

It must be an API v2 token. It starts with wl2_. Older API keys (v1) are not accepted by the v2 API; Wavelog 3.1.0 or later.

Create it in Wavelog: user menu → API → new API v2 token (name, scopes, expiry).

Required scopes:

  • logbook:read – list the logbooks and their station locations
  • qso:read – read the QSOs

Nothing more is needed; write and delete scopes stay unused. A ready-made preset works if it includes these two scopes; after "Load logbooks" the page checks the token, names missing scopes and points out unneeded write and delete scopes. Safest: just these two scopes and an expiry date.
