# v0.8.2

A documentation release: the **Notfunk manual** is reorganised into
`tutorial`, `manual` and `reference`, and the English edition of v0.8.1 is
removed again; the manual is German only. The tools themselves behave exactly
as in v0.8.1.

## Notfunk-Meldebuch manual

- **New structure:** the pages are grouped in the directories `tutorial/`,
  `manual/` and `reference/`, and the start page lists them in these three
  groups. The Sources moved from the start page to their own reference page.
- **File names:** all pages have English names and the language suffix `.de`,
  for example `manual/message.de.md`, so a site generator with language
  suffixes (such as Zensical) can pick them up.
- **Message path diagram:** "Der Weg einer Notmeldung" is redrawn with one
  arrow above the stations for the message and one below for the reply, a
  colour for each station, and an example message and reply on the arrows.
  The text in the stations is shorter; the details are in the text below it.
- **Narrow screens:** tables and links in the manual wrap instead of making
  the page wider than the screen.
- **No English edition:** the English introduction and tutorial of v0.8.1, and
  their entry on the overview page, are gone.

## Before updating

- Nothing to do for users: stored data, backups and exports are unchanged,
  and the tools' behaviour is unchanged.
- Sites that render `docs/` in their own theme (such as oe1ebg.at): the
  Notfunk manual pages moved again. They are now
  `docs/notfunk-anleitung/{tutorial,manual,reference}/<name>.de.md`, with the
  start page `index.de.md`. Pictures are linked as `../../img/…` from the sub
  pages. `english.md` no longer exists.
- The bundled manual stylesheet (`tools/shared/css/docs.css`) has new rules
  for the diagram caption (centred) and for wrapping long words in tables and
  links. A site with its own theme needs equivalent rules if it wants the same.
- The address `/tools/notfunk-anleitung/` (start page) stays, so the links in
  the tool still work. The bundled pages below it have new addresses, for
  example `/tools/notfunk-anleitung/manual/message/`; the address
  `/tools/notfunk-anleitung/english/` is gone.

## Limitations

- The message format of the Notfunk-Meldebuch is still a draft and not agreed
  with the Notfunkreferat Wien and the Meldesammelstelle.
- The limitations of v0.8.1 about screen readers, forced colours, the dark
  theme and unopened sources still apply.
- The tool still asks for MESZ or MEZ when a time falls into the repeated hour
  of the autumn clock change;
  [#153](https://github.com/oe1ebg/tools/issues/153) proposes to remove the
  choice.
