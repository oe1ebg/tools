# v0.7.0

This release makes **Confirm** and **Notfunk** easier to use on air and on
paper. Both get compact lists that show more at a glance, forms that ask for
less, and printouts written as PDF files that print the same in every
browser, including empty forms to print before an exercise. Notfunk gains an
offline map of its messages, the location search from Confirm, and a step
dialog for handing messages over. All tools share one header with help in the
same place and the same words for the same actions; the ADIF editor and the
SOTA Alerts Map can be switched between German and English.

## Notfunk-Meldebuch

- **Compact book:** one row per message with the number, time and
  reference (including "↪" the message a reply answers), the other party
  with ↓ (incoming) or ↑ (outgoing), the message type as a label, Dringend
  or Notfall in colour, the subject with two lines of text, and the status
  with its time and operator. The column names stay in view while scrolling
  on wide screens; on phones every message is a card.
- **Handing messages over:** the step button in a row ("übergeben",
  "Übernahme bestätigt", "übertragen", "Empfang bestätigt") opens a small
  dialog: to whom or by whom (names used in this operation are suggested),
  the time (empty = now) and, at the takeover of an incoming message, the
  Meldesammelstelle's reference. Enter records the step.
- **One message:** the type, direction and time on top, the reference under
  the subject, "Von → An" as on the paper form, the text, then small blocks
  for transmission, place, origin and remarks. A message with a place shows
  it on a **small offline map**; "Im Meldebuch zeigen" opens the book's map
  at that message.
- **Map ("Karte"):** the messages of the current list at their place on the
  offline map of Vienna, coloured by urgency, with the own station as a star.
- **Location search ("📍 Standort"):** the offline search from Confirm
  (address, place, postcode, coordinates, locator, UTMREF), now in Notfunk's
  header too.
- **Operation panel:** Esc in a field puts its value back; "Rückgängig"
  restores the panel as it was opened. An empty relay field says "direkt".
- **Printouts as PDF:** the message form (filled in, with all operation
  details; a long text continues on further pages), the book for a time
  range (A4 landscape, the full text of every message, Notfall and Dringend
  also framed for black-and-white printers) and the **empty form** for
  writing by hand (each choice a box to cross, writing lines at least 10 mm
  apart).
- **Fixed:** a place that could not be resolved was lost on saving although
  the field said it would be kept as text. It is now kept and shown as
  typed.

## Bestätigungsverkehr (Confirm)

- **Entry form for use on air:** the time field shows the running time with
  its zone; Name before RST; RST as two narrow fields "geg" / "erh" (type
  "57/59" straight through); the relay field holds the operation's relay and
  an empty field means "direkt" (no more "über" box); callsign fields as
  wide as a callsign.
- **"Betrieb" panel** (was "Vorgaben"): its closed line shows everything in
  it; Esc puts a field back; "Rückgängig" restores the panel as opened.
- **Compact log:** columns Nr, Zeit, Rufzeichen, Name, RST, Standort,
  Relais, Notiz, each as wide as it needs; a relay that differs from the
  operation is framed. The line being edited is marked ✎. On phones every
  line is a card.
- **Printouts as PDF:** "Drucken" writes the whole log (A4 landscape, oldest
  first, the operation details on every page); "Leerformular" gives an empty
  sheet to fill in by hand.

## Netlog

- Local times are named as people say them: "MESZ" / "MEZ" in German,
  "CEST" / "CET" in English, instead of "UTC+2".
- On phones, "+ Check in" stays above the callsign suggestions.
- Callsign fields are as wide as a callsign.

## ADIF editor and SOTA Alerts Map

- **German and English:** a DE/EN switch in the header, everything
  translated, including the validator's messages. The start language follows
  the browser until you choose.
- **ADIF:** the core fields (call, date, time, band, frequency, mode, RST,
  name, QTH, locator) come first in the table; "file order" shows the file's
  order. Exports keep the file's order as before.

## All tools

- **One header:** the way back, the title and the manual on the left, status
  in the middle, clock, language, theme and "? Hilfe" / "? Help" always on
  the right. On phones the header takes fewer lines.
- **The same words** for the same actions in every tool (Sichern,
  Wiederherstellen, Exportieren, Löschen …).
- **Updates:** a waiting new version is offered in a bar at the top, "Jetzt
  verwenden" / "Später"; "Später" keeps a button in the header.
- **Version:** the footer shows the release version next to the commit.
- **Location search:** a few well-known names (such as "Floridsdorfer
  Spitz") now find the place in Vienna, not a place of the same name
  elsewhere.

## Limitations

- Notfunk's message format is still provisional and not yet agreed with the
  Notfunkreferat Wien and the Krisenstab; fields and wording can change.
- The maps cover Vienna only.
- Netlog's help is in the app only; there is no separate manual yet
  ([#88](https://github.com/oe1ebg/tools/issues/88)).
- The new step dialog and message view were checked with automated browser
  tests on desktop and phone, not yet with a screen reader, at 200 % zoom or
  with forced colours.

## Before updating

- Export important logs and verify that the backup files arrived before
  updating, as for every release.
- For USB or `file://` use, replace downloaded single-file copies with this
  release's copies.
- Printouts now open as a PDF in a new tab (or download where the browser
  blocks the tab). Print from the PDF viewer at actual size (100 %).
- Stored data and exports are unchanged; Confirm's CSV and ADIF keep their
  columns. A Notfunk message with an unresolved place now stores that text;
  older versions do not show it.
- Server operators: the header configuration is unchanged since v0.5.0.
