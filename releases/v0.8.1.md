# v0.8.1

A documentation release: the **Notfunk manual** is rebuilt from one very long
page into a guided manual for operators, with an introduction to how an
emergency message travels in Vienna, a tutorial, and annotated pictures of the
form. The tools themselves behave exactly as in v0.8.0.

## Notfunk-Meldebuch manual

- **Structure:** the manual is a start page with sub pages (introduction,
  tutorial, preparation, operation, message, logbook, printout, backup,
  notices, keyboard) instead of one long page. The address
  `/tools/notfunk-anleitung/` is unchanged, so the link in the tool and its
  help still works.
- **Introduction:** how an emergency message travels from the Lichtinsel via
  the K-Vorsorgestandort and the radio station in the Einsatzleitstelle to the
  Meldesammelstelle of the Kriseneinsatzstab, and how the reply travels back,
  as a diagram. Radio amateurs are messengers: their part ends at the handover
  to the Meldesammelstelle, where they only note the reference. Reading back
  is recommended, not mandatory; every transmitted message belongs in the
  logbook. Based on the Richtlinie Notfunk Teil 2 – Wien of the Notfunkreferat.
- **Tutorial:** one example from taking down the message at a Lichtinsel to
  receiving the reply, with new screenshots.
- **Annotated forms:** pictures of the form in the tool and of the empty paper
  form with labelled fields, grouped by colour (and named in a legend).
- **Paper as a fallback:** the manual explains how to be prepared for
  paper-only operation, and the **empty form can be downloaded as a PDF**
  straight from the manual.
- **Offline preparation:** installing the tool as an app is the recommended
  way to run without internet, the single offline file for a USB stick the
  second; opening the address in a browser while offline is not reliable.
- **Reference rewritten** in plain language: implementation details such as
  storage, limits and file formats were removed.
- **English edition** of the introduction and tutorial, linked from the
  overview page.
- **Sources** the manual relies on are listed as links.

## All tools

- The manuals of the standalone bundle now have a page font and colours
  (they showed the browser defaults before).
- The overview page lists the English edition of the Notfunk manual.
- Stray files in the repository root (test leftovers) were removed.

## Limitations

- The message format of the Notfunk-Meldebuch is still a draft and not agreed
  with the Notfunkreferat Wien and the Meldesammelstelle.
- The new manual pages were not checked with a screen reader, in forced
  colours or in the dark theme. The annotated pictures carry the explanation
  in their alternative text and shrink on a narrow screen (a tap opens them
  at full size).
- Some linked sources were not opened while writing (SKKM guideline, ÖBFV
  E-31, the Lichtinsel articles, the W-KKG gazette); the Datenschutzgesetz
  link goes to the RIS home page. The steps to install the app in the
  different browsers are general guidance, not tried on every system.
- The English edition has no full reference, and the diagram labels are
  German in both editions.
- The tool still asks for MESZ or MEZ when a time falls into the repeated hour
  of the autumn clock change; the manual leaves this out on purpose, and
  [#153](https://github.com/oe1ebg/tools/issues/153) proposes to remove the
  choice.

## Before updating

- Nothing to do: stored data, backups and exports are unchanged, and the
  tools' behaviour is unchanged.
- Sites that render `docs/` in their own theme (such as oe1ebg.at): the Notfunk
  manual is now the directory `docs/notfunk-anleitung/` (`index.md` and sub
  pages, links relative to each source file, pictures as `../img/…`), the
  release stages the empty form as `downloads/notfunk-vordruck.pdf`, and
  `docs/static/` has one more committed picture. The URL
  `../notfunk-anleitung/` stays.
