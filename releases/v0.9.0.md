# v0.9.0

**Netlog gets statistics** over the sessions of a series, with a PDF and a CSV
export. **Notfunk-Meldebuch no longer asks for MESZ or MEZ** when a time falls
into the repeated hour of the autumn clock change, and its CSV now writes every
time as an absolute ISO 8601 value. The Notfunk manual has a presentation for
the introduction, and a new page title.

## Netlog

- **Series statistics.** On a series card in "Sessions & series" the new
  **Statistik / Statistics** button opens, below the card, a summary and four
  tables: the **regulars** (who took part in how many sessions of the series),
  the **attendance** of each station per session, the **sessions** (length,
  rounds with their durations, stations present, net control) and the **net
  control rotation**. Per station it shows the time present, the check-in time
  after the start of the session, the time as net control and the speaking
  time.
- **Speaking time is an estimate.** A turn is recorded with its start only, so
  its length is taken as the time until the next turn of the same round starts
  (an upper bound, because it includes pauses). It is marked as an estimate
  everywhere and is left out where the times are not exact.
- **Nothing invented.** A value calculated from estimated times is marked
  (`≈`, or "at least"); one that needs unknown times is left out, and the
  number of sessions and turns left out is shown. Stations are matched across
  sessions by their profile or their base callsign (`OE/DL0QXA/P` is
  `DL0QXA`); a callsign with `?` or `*` is not counted and is listed as
  excluded.
- **PDF and CSV.** Both are downloaded with one button each in the statistics
  panel. The PDF is a statistics sheet in the style of the roster PDF with the
  leaderboard, the attendance matrix, the sessions and the net control
  rotation. The CSV has one row per station and session (21 columns, `;`,
  times as ISO 8601 UTC, empty cells for unknown values, a quality column
  `exact | estimated | unknown`). They are exports, not backups: they do not
  change the backup status.
- Nothing changes in the stored data, so backups and sessions of earlier
  versions work as before. The statistics are calculated from the records on
  the device when the panel is opened, nothing is sent anywhere. They exist for
  series only: a session without a series has no series card.

## Notfunk-Meldebuch

- **No MESZ/MEZ choice.** When the clocks go back in October, 02:00–02:59
  happens twice. The form no longer asks which one is meant, and the zone name
  is gone from the form, the logbook, the printouts and the help. If "now" is
  itself in the repeated hour, the time you enter means the occurrence nearest
  to now; otherwise it means the first one. A time ahead of now in that hour
  can therefore be read as the other occurrence and then shows the existing
  warning that the time lies in the future.
- **The missing hour in March** is still rejected, with a message that says
  what to enter instead.
- **Stored times were always absolute** (UTC instants), so no message changes:
  messages and drafts of earlier versions show the same times, and old drafts
  that still carry the zone choice are restored (the choice is dropped).
- **CSV: all times are absolute.** In the Notfunk CSV the time cells now hold
  ISO 8601 values with the offset from UTC, in the same columns as before:
  "Uhrzeit" is `14:07:00+02:00` (it was `14:07`), "Übergeben / übertragen
  um", "Übernommen / Empfang bestätigt durch" (after the name) and "Erfasst"
  are `2026-10-05T14:07:00+02:00` (they were wall-clock times). No column was
  added or moved. The column
  "Zeitstempel (ISO 8601)" is as before.
- **Manual:** the start page of the manual is called "Notfunk-Meldebuch" (it
  was "Notfunk-Meldebuch: Anleitung"), also in the browser tab and on the
  overview page. The start page has a new section **Präsentation** with the
  introduction as PDF and as an HTML slide show you can page through in the
  browser. The same slides are available as PowerPoint files, which are not
  linked: `downloads/notfunk-einfuehrung/notfunk-einfuehrung.pptx` (with the
  font IBM Plex Sans) and `notfunk-einfuehrung-basic.pptx` (standard fonts).
- **Message path diagram:** the stations are labelled by the direction through
  the network: Lichtinsel "Eingang ↓", K-Vorsorgestandort "Weitergabe ↔",
  Funkstelle der ELS "Ausgang ↑".

## Before updating

- **Nothing to do for users:** stored data, backups and the format of the
  JSON backups are unchanged.
- **Anyone reading the Notfunk CSV with a program** has to expect ISO 8601
  values with an offset in the time cells named above.
- **Sites that render `docs/` and rewrite the title of the Notfunk manual start
  page** (such as oe1ebg.at) must update: the heading in
  `docs/notfunk-anleitung/index.de.md` is now `# Notfunk-Meldebuch`. A staging
  step that looks for the old heading `# Notfunk-Meldebuch: Anleitung` fails
  ([#160](https://github.com/oe1ebg/tools/issues/160) is still open for the
  site side).
- **Servers with their own security headers:** the bundle now contains
  `downloads/notfunk-einfuehrung/` (PDF, HTML, PowerPoint). The HTML slide show
  has an inline script and style. `deploy/nginx.conf.example` and
  `deploy/htaccess.example` give that directory (and only it) the inline policy
  that the single-file bundles have, without any network host. Without that
  rule the HTML slides show unstyled and do not page; the other files are not
  affected. The slides ask for the font IBM Plex Sans from Google Fonts; that
  host stays blocked, so a system font is shown there
  ([#161](https://github.com/oe1ebg/tools/issues/161)). A saved copy opened
  with internet access loads the font.

## Limitations

- The message format of the Notfunk-Meldebuch is still a draft and not agreed
  with the Notfunkreferat Wien and the Meldesammelstelle.
- In the Notfunk manual, "Eingang" and "Ausgang" mean two things: in the
  message path diagram the direction through the network, in the table below
  it and in the tool the view of each station (the Lichtinsel's message to the
  Stab is an "Ausgang ↑" there).
- The Netlog statistics are per series. A date range filter, merging stations
  by hand and statistics across series are not included. Speaking time is an
  estimate.
- The accessibility checks with axe-core in the new statistics tests run only
  where axe-core is installed (not in CI), and a screen-reader check of the
  statistics was not done. The limitations of v0.8.1 about screen readers,
  forced colours and the dark theme still apply.
- A test of the Confirm tool on a phone layout fails by a pixel or two
  ([#167](https://github.com/oe1ebg/tools/issues/167)); it is not caused by
  this release.
