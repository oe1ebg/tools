# v0.3.0

This release improves saving, backup restoration, and updates in the offline
tools. Larger logs are more responsive, the ADIF editor shows progress during
import, and the Notfunk form is easier to use.

## Confirmation log and Notfunk

- More responsive editing and work with larger logs.
- Improved handling of interrupted saves, browser-storage problems, and
  conflicting edits in another tab.
- Safer backup restoration, with clearer explanations when records cannot be
  restored. Restoring Notfunk backups protects newer changes and message numbers;
  importing Confirm backups copies colliding logs instead of overwriting them.
- Large backups can be downloaded in several parts and restored together,
  including long texts and revision history, within the supported limits.
- Clearer notices distinguish saved entries, drafts, and backup downloads.
- CSV exports better protect against spreadsheet programs interpreting text
  as formulas.

## Notfunk-Meldebuch

- A simpler entry form and print layout, with the station callsign in operation
  details.
- Improved local date/time entry, daylight-saving handling, and restoration of
  manually entered times.
- Open a message directly by clicking its row in the message book.
- The tool remains a draft: its format is provisional until confirmed by the
  Notfunkreferat Wien.

## ADIF editor

- File imports show progress and can be cancelled.
- Validation stays more responsive while working with larger files.
- Improved handling of field lengths, international characters, custom fields,
  and malformed files. Very large inputs are refused with an explanation rather
  than being loaded without bounds.

## Offline tools and SOTA Alerts Map

- More resilient offline installation and updates, including clearer notices
  when an update must wait for work to be saved.
- Confirm and Notfunk can be installed as distinct apps.
- SOTA refreshes and searches handle slow or failed requests more reliably.
  Failed refreshes retain the last-known alerts, marked as stale.
- Summit lookup and shared links have safeguards to avoid excessive live requests.

## Before updating

- Export important logs and verify that the backup files arrived before updating.
  A message saying a download started does not confirm that a backup was retained.
- For a split backup, keep **all parts** and select them together when restoring
  in the updated version of the same tool. Older versions cannot safely restore
  backups containing text chunks. Browsers may block multiple automatic downloads;
  check that every part arrived.
- For USB or `file://` use, replace downloaded single-file copies with this
  release's copies.
- If an existing installed app opens the wrong tool, back up both tools first
  and follow the [app installation guidance](https://github.com/oe1ebg/tools/blob/v0.3.0/tools/confirm/README.md#how-it-is-used-offline).
  Do not clear site data when removing an old installation.
- Server operators: follow the [deployment instructions](https://github.com/oe1ebg/tools/blob/v0.3.0/README.md#updating-a-deployment-atomically)
  and review the supplied header configuration when updating.
