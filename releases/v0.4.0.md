# v0.4.0

This release brings the ADIF editor to ADIF 3.1.8 and adds ADX files, log
statistics, dropdowns for enumerated fields, and ISO date and time cells. All
tools now show dates as `YYYY-MM-DD` and times in 24-hour form, independent of
the browser language. Offline updates in Confirm and Notfunk are more reliable.

## ADIF editor

- Follows ADIF 3.1.8, including the new MFSK submode JTTY, four SKCC contest IDs and
  updated region information. Exports declare version 3.1.8.
- Opens, edits and exports ADX (XML) files as well as ADI. Converting between
  the two formats asks for a decision wherever information would change or be
  lost, for example international characters in an ADI export; the loaded log
  itself stays unchanged.
- A short log overview and expandable statistics for the whole log or the
  shown QSOs: callsigns, dates, bands, modes, DXCC entities, and how complete
  each field is.
- Fields with a fixed list of values (BAND, MODE, DXCC, QSL status, and
  others) are dropdowns. CONTEST_ID and SUBMODE suggest values while you type
  and still accept others. Existing values outside the list are kept and marked.
- Dates are shown and entered as `2026-09-01` and times as `12:00` or
  `12:00:30`; files still store ADIF's `20260901` and `1200`. A calendar button
  helps pick dates. Viewing or tabbing through a log changes nothing.
- The date filter takes ISO dates instead of the browser's local date format.
- **new** starts an empty log and **clear…** empties the editor.
- The controls above the table fold away while the table is scrolled, leaving
  more room for QSOs, especially on phones.

## Confirmation log and Notfunk

- No more false “Update verfügbar” on the first visit in Safari.
- An Update click is no longer lost when an even newer version finishes
  installing at the same moment.
- The page header no longer jumps while offline use is being set up; the setup
  message now reads “offline: lädt…”.
- Splitting a large backup into parts is faster.

## SOTA Alerts Map

- Alert times and the date range use ISO dates and 24-hour times in every
  browser language. The date range has ISO fields with a calendar button.

## Before updating

- Export important logs and verify that the backup files arrived before
  updating, as for every release.
- ADIF editor: exports now declare ADIF 3.1.8. If another program needs the
  3.1.7 header, check it before relying on new exports.
- For USB or `file://` use, replace downloaded single-file copies with this
  release's copies.
- Server operators: follow the [deployment instructions](https://github.com/oe1ebg/tools/blob/v0.4.0/README.md#updating-a-deployment-atomically)
  and review the supplied header configuration when updating.
