oe1ebg tools: previews and builds

Builds of the oe1ebg tools: main, open pull requests and releases. A branch without an open pull request has no preview.

Do not use real data here. Every entry on this site is served from the same browser origin. The tools store their logbooks, drafts and settings per origin (IndexedDB, localStorage), so all entries share one local logbook, and every entry (including a pull request preview of code nobody has reviewed yet) can read and change it. Their service workers also share the origin’s cache storage.

Use a separate browser profile for trying previews, test data only. Real logbooks belong on a dedicated origin such as oe1ebg.at/tools/.

These are static previews without the security headers of the nginx example (Content-Security-Policy, framing protection); they do not replace the CI checks.
